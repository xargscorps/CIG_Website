# Content Update Guide

## Company text and sections

Edit `index.html` to update:

- Headlines and descriptions
- Services and solutions
- Statistics
- Industries
- Delivery lifecycle
- Address, phone number, email address and working hours
- SEO title, description and structured business information

## Colors, spacing and responsive design

Edit `src/styles/main.css`.

The main brand colors are declared near the top under `:root`. The primary blue is `#1256E0`.

## Animations and interactions

Edit `src/scripts/main.js` to update:

- Mobile navigation
- Service dropdown behavior
- Scroll reveals
- Parallax motion
- Statistics counters
- Card and button interactions
- Current-section navigation feedback

## Logo and social preview

- Main logo: `public/assets/images/cloudinfra-global-logo.png`
- Social sharing image: `public/assets/images/cloudinfra-global-social-preview.png`

Keep these filenames when replacing the files so no code changes are required.

## Platform logos

Platform assets are stored in `public/assets/platforms`. Keep the existing filenames if updated versions are supplied.
